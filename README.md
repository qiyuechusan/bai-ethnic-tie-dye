# 蓝白之境

白族扎染非遗数字科普站的登录页与主页面视觉原型。

## 预览

直接双击 `index.html` 即可打开登录页，输入任意账号与密码进入主页面；也可以点击“暂不登录，先逛一逛”直接浏览主页面。

## 页面

- `index.html`：沉浸式登录页
- `home.html`：六大展区主页面
- `styles.css`：全局视觉、动效与响应式样式
- `app.js`：靛蓝晕染背景、登录交互、滚动动效
- `assets/indigo-textile.svg`：原创扎染蝴蝶花卉纹样矢量图
- `preview-login.png`、`preview-home.png`：桌面端视觉预览

当前为界面原型，六个展区与后台管理功能均未接入业务逻辑。
